# Разбор rom4ikk1/cleanyourtv-ru v2.0-ru и изменения персонального форка

Проверены исходники именно [тега v2.0-ru](https://github.com/rom4ikk1/cleanyourtv-ru/tree/v2.0-ru), а не только текст релиза. Внешний APK не устанавливался; личный форк сохраняет свой ключ сборки и обновляется из исходников. Автор интерфейса-образца — rom4ikk1; исходный проект Gathin23/cleanyourtv распространяется под MIT, лицензия сохраняется в корне репозитория. Новый код полки реализован в персональном форке, с использованием идей интерфейса образца.

| Что проверено | Наблюдение в v2.0-ru | Изменение здесь |
|---|---|---|
| Постеры и описание (`ContentRow`) | Вертикальные карточки и фон выбранного материала | Вертикальные карточки, описание, серия, год, опубликованная оценка, фон и прогресс |
| Отсутствующая картинка | Карточки без URI и с ошибкой загрузки исключаются | Название остаётся доступным; сбой картинки не скрывает историю |
| Источник новинок (`TvRows.newMovies`) | Для части приложений используются фильмы ivi с поиском в другом сервисе | Продолжение, новые серии, новинки, избранное и каналы группируются по данным самого выбранного приложения |
| Названия рядов | Продолжение и история из Android TV; затем подборки и каталоги | Исходные названия каналов сохраняются; чужой каталог не выдаётся за историю аккаунта |
| Обновление данных | `refresh()` создаёт новый поток и перечитывает данные всех приложений | Один отменяемый запрос для выбранного приложения; debounce, поколение запроса и отложенное обновление при фокусе на карточке |
| Память изображений | Кеши постеров и фонов на 12 + 16 МиБ | Общий кеш до 8 МиБ, два потока, ограничение входа 4 МиБ и декодирования 512/1280 пикселей |
| Жизненный цикл | Освобождение загрузчиков при уничтожении экрана | Уход с Home отменяет запросы, закрывает соединения и загрузчики; старый ответ не меняет новый экран |
| Открытие фильма | Intent опубликованного материала либо поиск в другом приложении | Intent закреплён за приложением-источником; selector и гранты URI очищаются |
| VPN (`AppVpn`, `vpn.xml`) | Incy; `vpn_keep_on=true` удерживает туннель включённым | Сохраняется Happ и отдельные connect/disconnect при входе/выходе из YouTube/SmartTube |
| Запуск YouTube | Ожидание VPN до восьми секунд при запуске из лаунчера | Служба получает переходы из любого приложения и кнопки пульта; команда Happ не считается подтверждением подключения |
| Настройка службы | Перехватчики кнопок пульта и ресурсы сборки | Отдельная служба без чтения экрана и перехвата кнопок; статус её подключения показан в настройках |
| Ограниченные настройки | Простая запись enabled-accessibility недостаточна на части новых ТВ | Отдельная процедура ADB разрешает ограниченные настройки только CleanYourTV, сохраняет резервную копию и проверяет подключение |
| Android 14 | Выгрузка чужих процессов ограничена системой | Настройка недоступна и явно подписана; ADB-настройка оставляет её выключенной |
| Windows/JDK | Сборке нужен JDK 17 | Проверяются версия, javac и jlink; Gradle получает явный путь к JDK 17, Java 25 не подхватывается |

В APK персонального форка добавлено разрешение `INTERNET` для изображений видимой полки. Сетевые постеры отключаются отдельным переключателем; картинки не записываются на диск. HTTP оставлен для старых опубликованных постеров, как в исходном русском форке. Приложение не получает доступ к приватной истории аккаунтов или базам других приложений. Погода, каталоги ivi, NUM и поисковые интеграции из образца не включены в новый код полки: они требуют отдельных источников и настроек и не улучшают полноту опубликованной истории выбранного приложения.

Для сохранения лимита 589 824 байта персональный APK упаковывает русский и английский языки. Все исходные переводы остаются в `src/main/res`; языковые списки debug/release переопределены согласованно. Пакет — `com.gathin.tvhome`, версия `3.3-ru`, versionCode 13. В 3.3 возвращена обычная сетка под доком и добавлен выбор приложений для авто-VPN; библиотека не навязывается.

## Проверка и практические пределы

JVM-тесты проверяют группировку рядов, сохранение карточки без постера, отсутствие выдуманной истории, лимит скачивания, отмену потока и уменьшение изображения. Python-проверки защищают контракт разрешений RPC настройки, ограниченный набор флагов, сохранение сторонних служб и запрет выгрузки на Android 14. Lint и APK проверяются обычными задачами проекта.

Без доступа к телевизору нельзя подтвердить навигацию реальным пультом, опубликованные конкретным видеосервисом данные, подпись установленного APK и выполнение команд конкретной версией Happ. Эти проверки описаны в [инструкции настройки](favorites-history-happ.ru.md). Статус `service_bound` подтверждает подключение службы, но не подключение VPN-сервера.

Присланный журнал Android 14 показал отказ `Skipping enabling service disallowed by device admin policy`; разрешение `ACCESS_RESTRICTED_SETTINGS` для одного CleanYourTV устранило этот отказ, после чего служба появилась в Bound services. Отдельная ошибка SQLite процесса `com.mediatek.tv.agent` относится к системной службе изображения. Доказательств, что её исправит обновление лаунчера, нет; её данные не сбрасываются и пакет не отключается.

## Уточнения версии 3.3

По просьбе владельца обычная сетка приложений снова видна под доком. Встроенная библиотека не менялась и по умолчанию выключена. Одноразовая миграция сохраняет избранное, порядок и VPN, меняя только single_row, app_library, library_button и минимальное число рядов под доком. Визуальный блок просмотра использует родные шрифты, стеклянный фокус и скругления лаунчера, а не стили стороннего медиаплеера. Для него не резервируется высота за счёт сетки; в небольшом доступном пространстве используются компактные широкие карточки.

Авто-VPN получает набор отмеченных установленных приложений из настроек. По умолчанию остаются YouTube и SmartTube. Переключение между выбранными приложениями не дёргает туннель. Смена списка не сбрасывает текущее приложение и таймеры фоновой выгрузки. Выбор системного приложения для VPN не добавляет его в список разрешённой выгрузки.
